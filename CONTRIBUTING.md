# Contributing to SimpleUI

Issues and pull requests are welcome at
<https://github.com/LuislopezMartinez/SimpleUI>.

Before submitting a change:

1. Keep the public APIs in `simpleui.desktop` and `simpleui.android` aligned,
   except for documented platform services in `SimpleUI`.
2. Add or update an example when behavior visible to Processing users changes.
3. Run `./build.ps1` from PowerShell.
4. Do not commit files from `build/`, `release/` or `.deps/`.

By contributing, you agree that your contribution is distributed under the
MIT License used by this project.
